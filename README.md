# travel-blog
To write my own travel blog with pictures etc.

## Writing a post

1. Open Terminal and run:

   ```bash
   cd ~/travel-blog && python3 write.py
   ```

2. The writing desk opens in your browser. Give the post a title, write your story, and use **Add photos** to drop pictures into it.
3. Press **Save**, then **View post** to see how it looks.
4. Press **Publish to website** to put it online.

When you are done, go back to Terminal and press Ctrl+C.

## What is where

- `site.json` — the blog's name, tagline and author
- `posts/` — the text of each post
- `images/` — the photos
- `assets/style.css` — colours, fonts and layout
- `write.py`, `admin/` — the writing desk (only runs on your own computer)
